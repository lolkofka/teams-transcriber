# Внешний обработчик звука в Docker

Контейнер поднимает `processor_server.py` (faster-whisper) на порту 8756. Приложение на домашнем ПК шлёт туда куски
речи и получает текст; нарезка речи, спикеры, слайды и файлы остаются на домашнем ПК.

## Что залить на сервер

Три файла из этой папки плюс сам сервер, всё в одну директорию:

```
processor_server.py      (лежит на уровень выше, в корне проекта)
deploy/Dockerfile
deploy/docker-compose.yml
deploy/entrypoint.sh
```

Одной командой с домашнего ПК (PowerShell):

```bat
scp processor_server.py deploy\Dockerfile deploy\docker-compose.yml deploy\entrypoint.sh ПОЛЬЗОВАТЕЛЬ@СЕРВЕР:~/teams-processor/
```

## Запуск на сервере

```bash
cd ~/teams-processor
python3 -c "import secrets;print('TOKEN='+secrets.token_urlsafe(24))" > .env   # токен
docker compose up -d --build
docker compose logs -f          # первый старт качает модель ~1.6 ГБ
```

Токен посмотреть: `cat .env`.

Проверка на самом сервере:

```bash
curl -H "X-Token: $(grep TOKEN .env | cut -d= -f2)" http://127.0.0.1:8756/health
```

## Видеокарта

В `docker-compose.yml` раскомментировать `BASE: nvidia/cuda:...`, поставить `DEVICE: cuda` и секцию
`deploy.resources.devices`, затем `docker compose up -d --build`. Нужен установленный NVIDIA Container Toolkit.
Без видеокарты всё работает на процессоре, просто медленнее.

## Подключение с домашнего ПК

Порт наружу не открыт (слушает `127.0.0.1` на сервере), трафик не шифрован, поэтому подключение через SSH-туннель.
Эту команду держать запущенной во время пар:

```bash
ssh -N -L 8756:127.0.0.1:8756 ПОЛЬЗОВАТЕЛЬ@СЕРВЕР
```

В приложении: Настройки → Обработчик звука → внешний сервер, адрес `http://127.0.0.1:8756`, токен из `.env`,
кнопка «Проверить связь» покажет устройство, число потоков и модель. Мощность (модель) выбирается там же.

## Настройки контейнера

| Переменная в `.env` | По умолчанию | Смысл |
|---|---|---|
| `TOKEN` | обязателен | общий секрет, тот же вписывается в приложении |
| `MODEL` | `large-v3-turbo` | модель по умолчанию; приложение может просить другую |
| `DEVICE` | `cpu` | `cuda` для видеокарты |
| `THREADS` | `0` | 0 = все ядра контейнера |
| `MAX_BEAM` | `5` | потолок ширины поиска для клиентов |

Модели лежат в томе `models`, пересоздание контейнера их не теряет. Остановить: `docker compose down`.
