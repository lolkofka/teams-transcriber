# TeamsTranscriber для Mac с Apple Silicon

## Общий архив пар

Кнопка **Архив пар** открывает общую историю на сервере с просмотром текста/чата, скачиванием TXT/JSON и всех загруженных материалов без сжатия. Подключение задаётся в настройках или отдельным `archive-connection.json`; этот файл не содержит учётных данных Teams. Текстовая история автоматически сохраняется локально в `recordings/shared/`. Аудио и прочие нетекстовые материалы передаются после завершения записи и удаляются с ПК через три дня после конца пары только при подтверждённой загрузке. Очистка выполняется исключительно работающей программой. Подробности: `deploy/README-archive.md`.

Сборка находится в архиве `TeamsTranscriber-macos-arm64.zip` из GitHub Actions. Распакуйте архив на Mac и перенесите `TeamsTranscriber.app` в «Программы». Приложение собрано для `arm64` и подписано временной подписью; для первого запуска может понадобиться открыть его через контекстное меню «Открыть» и подтвердить запуск в настройках конфиденциальности macOS.

## Запись звука Teams

Прослушивание не зависит от записи: встроенный Teams играет звук на выбранный в Teams динамик до нажатия «Старт» и после «Стоп». Для виртуального аудиовхода пересылка на выбранный **Выход** транскрибера также работает без записи. Выберите вход и выход в настройках; громкость применяется сразу. Чтобы выключить пересылку, выберите выход «не играть». Само прослушивание не создаёт WAV или транскрипт и не загружает Whisper.

Ползунок **Звук** на верхней панели управляет громкостью прослушивания: крайнее левое положение — **0%**, полная тишина. Он работает и для встроенного Teams без начатой записи, сохраняет уровень после перезапуска и не меняет громкость входящего аудио в WAV и распознавании. Значение синхронизировано с громкостью в настройках.

Для встроенного Teams виртуальный аудиокабель не нужен:

1. Нажмите **Открыть Teams**, войдите в аккаунт и откройте собрание в этом окне.
2. В настройках транскрибера выберите вход **Teams — звук встроенного окна** (выбран по умолчанию при первом запуске на Mac).
3. Нажмите **Старт**. Входящие аудиодорожки звонка передаются напрямую в распознавание и WAV. Teams продолжает играть звук на обычное устройство; выход и громкость пересылки транскрибера в этом режиме не используются.

Перехват устанавливается до загрузки Teams и действует также после переходов между страницами. Остановка записи не закрывает звонок. Если звук не поступает, нажмите любую кнопку в окне Teams: WebKit может приостановить аудиоконтекст до действия пользователя. Этот режим рассчитан на WebRTC в страницах `teams.microsoft.com` и `teams.cloud.microsoft`; изменения реализации Teams (например, перенос звонка в отдельный worker) могут потребовать обновления перехвата.

Для отдельного приложения Teams или внешнего браузера используйте виртуальное аудиоустройство [BlackHole 2ch](https://existential.audio/blackhole/): выберите его как **динамик в настройках Teams**, а в транскрибере как **вход**. Для прослушивания выберите в программе свои наушники как **выход**. Не выбирайте BlackHole выходом программы: это создаст звуковую петлю. Для записи собственного микрофона разрешите доступ к нему в macOS.

Если нужны и запись, и системное воспроизведение звука Teams, оставьте выход Teams на BlackHole, а прослушивание включите через выход TeamsTranscriber. При первом запуске модели Whisper и ECAPA скачиваются из интернета; Vosk для быстрого черновика включён в архив.

В собранном приложении настройки, модели и записи лежат в `~/Library/Application Support/TeamsTranscriber/`; при запуске исходников — в папке проекта. Можно открыть папку записей кнопкой в приложении.

## Сообщения чата в транскрипции

На Mac при записи откройте панель **Чат** внутри собрания Teams и оставьте её открытой. Загруженные сообщения текущей пары сохраняются в `transcript.txt` и `transcript.jsonl` с исходным временем, именем автора и пометкой **чат**. В ленте они сортируются по времени; пометка также появляется в конспекте DOCX/PDF. Повторное появление сообщения и перезапуск записи не создают дублей.

Собирается только отображённый чат собрания. Закрытая панель и сообщения, которые Teams ещё не загрузил при прокрутке, недоступны. Вложения не скачиваются; сохраняется отображаемый текст. Сообщения без определяемой даты или автора пропускаются. Изменения уже сохранённых сообщений пока не заменяют исходный текст.

## Автовход в собрание

Встроенное окно разрешает микрофон сайтам `https://teams.microsoft.com` и `https://teams.cloud.microsoft`, если и страница, и запрашивающий фрейм принадлежат Teams. Поэтому запрос WebKit «Allow microphone» не повторяется при каждом входе. Системное разрешение macOS остаётся обязательным, камера требует отдельного подтверждения. Автовход по-прежнему выключает микрофон и камеру перед подключением.

Микрофон во встроенном Teams по умолчанию выключен также при ручном входе и переподключении. Передача звука разрешается только после нажатия пользователем кнопки микрофона или сочетания клавиш управления микрофоном. При потере/восстановлении сети, сбое WebRTC или появлении нового экрана входа разрешение сбрасывается: микрофон нужно включить вручную заново. Эта защита действует внутри страницы и не зависит от доступа к журналу расписания. Входящий звук собрания продолжает записываться.

Список физических камер на Mac читается через AVFoundation; доступны встроенная FaceTime, USB-камеры и камера iPhone, если её предоставляет macOS. Для записи ролика потребуется системное разрешение камеры. Физическая камера и виртуальная камера для проигрывания видео — отдельные устройства: список физических камер не устанавливает драйвер виртуальной камеры.

Ролик с физической камеры на Mac записывается через нативные `getUserMedia`/`MediaRecorder` WebKit, с живым предпросмотром в настройках и во время отсчёта. Используется только видео, микрофон не запрашивается. При первом запуске разрешите камеру локальной странице `127.0.0.1`. Фрагменты сохраняются в MP4, готовый файл проверяется перед выбором для виртуальной камеры. Чёрное изображение и ошибки сохранения выводятся явно; для проигрывания ролика в Teams всё ещё нужен драйвер виртуальной камеры.

Автовход работает во встроенном Teams на Mac и Windows. Один раз войдите в свой Microsoft-аккаунт через **Открыть Teams**; вход в журнал не заменяет вход в Teams. Учётная запись журнала настраивается в разделе «Журнал», автоматизация берёт из него расписание и ищет одно приглашение в календаре Teams с соответствующим временем начала (допуск 10 минут).

В настройках включите **Входить в собрание в начале пары из расписания top-academy**. Оставьте приложение открытым: за 10 минут до пары оно открывает Teams и календарь, в первые 5 минут после начала пробует войти. Перед входом камера и микрофон должны быть явно подтверждены выключенными. При неясных переключателях, нескольких совпадающих приглашениях или отсутствии календаря автоматизация пишет причину в журнал событий. Неудачный вход повторяется через 30 секунд, максимум три попытки в пределах окна входа.

Автовыход требует одновременно окончания пары, прощания в расшифровке и подтверждения, что в собрании остался один участник. Если распознавание выключено или число участников недоступно, автоматический выход не выполняется.

Проверка полного сценария в локальном WKWebView без аккаунта и реального собрания: `PYTHONPATH=. .venv/bin/python tests/webview_autojoin_smoke.py`.

## Ограничения версии для macOS

Автоматическое сохранение слайдов Teams, отслеживание кнопки микрофона Teams, установка VB-Cable и UnityCapture требуют Windows. Для записи собственного голоса выберите режим «всегда». Виртуальную камеру можно использовать через OBS Virtual Camera, если она доступна на Mac.

## Сборка из исходников

Для запуска исходников с нормальной иконкой в Dock и переключателе приложений откройте `run-macos.command`. При первом запуске он создаёт `dist/TeamsTranscriber.app` (нужны Xcode Command Line Tools). Этот небольшой запускатель использует `.venv` и исходники проекта, поэтому переносить его отдельно нельзя. Для пересоздания после переноса проекта выполните `.venv/bin/python build_macos_launcher.py`. В меню **Окно** доступны **Транскрибер (⌘1)** и **Teams (⌘2)**. После перехода с запуска через Python в новом окне Teams нужно один раз войти заново.

На Mac с Apple Silicon и Python 3.11:

```sh
brew install portaudio
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-macos.txt
python app.py  # запуск без сборки; также можно открыть run-macos.command
python -m PyInstaller --noconfirm --clean TeamsTranscriber-macos.spec
```

Запуск исходников также задаёт описания доступа к микрофону и камере до создания WebKit. Без них Teams может войти в аккаунт, но показать ошибку «You can't receive or make calls right now»: WebKit не предоставляет `navigator.mediaDevices`. Разрешения на устройства по-прежнему запрашивает macOS. Проверка доступности API без открытия микрофона и камеры: `PYTHONPATH=. .venv/bin/python tests/webview_media_smoke.py`.

Для включения Vosk поместите `models/vosk-model-small-ru-0.22` в репозиторий до сборки. Готовое приложение: `dist/TeamsTranscriber.app`.

Проверка прямого захвата на Mac без аккаунта Teams и микрофона: `PYTHONPATH=. .venv/bin/python tests/webview_audio_smoke.py`. Тест создаёт локальный WebRTC-звонок с тоном и проверяет получение PCM и сохранение WAV через настоящий WKWebView.

Полное руководство по всем функциям, общему архиву и очистке: [USER-GUIDE.txt](USER-GUIDE.txt).
