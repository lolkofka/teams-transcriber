# Teams transcriber — пояснительная записка для новой сессии

Локальная программа для Windows: пишет звук пары в Microsoft Teams, распознаёт в реальном времени, привязывает запись
к паре из журнала top-academy, ловит слайды с показа экрана, собирает конспект, подсказывает ответ, когда зовут по имени,
умеет подменять веб-камеру роликом. Всё на Python 3.11 в `.venv`, интерфейс на pywebview (Edge WebView2).
Подробности по каждой функции в `README.md`, эта записка про устройство и текущее состояние.

Репозиторий: https://github.com/lolkofka/teams-transcriber (private, ветка `main`; секреты, записи, модели и сборки в `.gitignore`).

## Как запускать

- `app.bat` (или ярлык «Teams transcriber» на рабочем столе) — основное окно. Процесс `pythonw.exe app.py`.
- Перезапуск из Claude: убить `pythonw`, запустить заново через `Start-Process .venv\Scripts\pythonw.exe app.py`.
  **Не перезапускать во время пары без спроса**: убивается запись. Признак записи: `recordings\...\transcript.txt`
  менялся в последние минуты и процесс весит > 1 ГБ.
- `run.bat` — старая консольная версия того же конвейера (`transcribe.py` с флагами).
- `processor.bat` — внешний обработчик звука на этой машине (порт 8756, токен в `proc_token.txt`).
- Сборка для других людей: `.venv\Scripts\pyinstaller --noconfirm TeamsTranscriber.spec` затем
  `.venv\Scripts\python build_dist.py` → `dist\TeamsTranscriber-<дата>.zip` (~490 МБ). Занимает 6–8 минут.
  Проверка сборки: `dist\TeamsTranscriber\TeamsTranscriber.exe --selftest` пишет `selftest.log`.

## Архитектура (файлы)

| Файл | Что делает |
|---|---|
| `app.py` | pywebview-окно + класс `Api` (мост JS↔Python). Держит конвейер, анализатор, оповещения, слайды, камеру, уведомления. **Все не-API атрибуты `Api` начинаются с `_`**: pywebview рекурсивно обходит публичные атрибуты и на объекте окна зависает намертво. |
| `ui/index.html` | Весь интерфейс в одном файле (CSS+JS). Открыть в браузере с `?mock=1` — демо без бэкенда. События из Python приходят в `window.__evt({kind,...})`. |
| `transcribe.py` | Конвейер: `Recorder` (WASAPI loopback / микрофон, pyaudiowpatch) → `Segmenter` (Silero VAD) → `Transcriber` (faster-whisper large-v3-turbo, int8, CPU; батчи до 28 с; спикеры через ECAPA `SpeakerTracker`). `Drafter` — мгновенный черновик Vosk. `Pipeline` собирает всё. `RemoteWhisper` — клиент внешнего обработчика: при быстрой ошибке сети повторяет запрос через 1.5 с, при провале откатывается на локальную модель и раз в 20 с проверяет `/health` в фоне, при ответе сам возвращается на сервер (сообщения `[proc] …` в журнале). `PA_LOCK` сериализует открытие аудиоустройств (параллельное открытие роняет PortAudio). |
| `processor_server.py` | HTTP-сервер обработчика (stdlib), `/health` и `/transcribe`, токен в заголовке `X-Token`, модели грузятся по требованию, `--max-beam`, `--no-model-switch`. |
| `journal.py` | API журнала top-academy (MyStat): расписание, посещения, оценки, имя папки пары. Логин/пароль в `journal.json`, токен кэшируется в `journal_token.json`. |
| `analyst.py` | Анализ пары через OpenAI-совместимый чат-API (тема/задание/тезисы), вопросы по паре, быстрая подсказка при пинге. Для Gemini выставляет `reasoning_effort: low` и большой `max_tokens`. |
| `alerts.py` | Пинг по имени: regex по началу слова, звук на выбранное устройство. |
| `slides.py` | Кадры с показа экрана: элемент «Общий контент от пользователя …» в окне звонка (UI Automation), снимок только через PrintWindow, dHash-дедупликация. **Без снимков экрана** — иначе в кадр попадают чужие окна. |
| `report.py` | Конспект DOCX/PDF из папки пары. |
| `notify.py` | Уведомление Windows о начале пары (winotify) + автостарт записи. |
| `teams_mic.py` | Следит за кнопкой микрофона в окне звонка Teams (`AutomationId=microphone-button`, «Включить микрофон» = выключен). |
| `vcam.py` | Виртуальная камера (pyvirtualcam → Unity Capture), запись ролика с вебки, регистрация драйвера под своим именем. |
| `vcable.py`, `vcable_rename.py` | Виртуальный аудиокабель VB-Cable: установка и переименование устройств через IPropertyStore с UAC (реестр MMDevices закрыт даже для SYSTEM). |
| `paths.py` | `BASE_DIR`: папка проекта или папка с exe в сборке. |
| `gui.py` | Старый Tk-интерфейс, запасной. |
| `deploy/` | Докер и скрипт установки обработчика на Linux-сервер, инструкция в `deploy/README.md`. |

Данные: `recordings\<Предмет>\<дата_начало>\` → `transcript.txt` (спикеры, техзаголовок), `transcript.jsonl`,
`audio__*.wav`, `mic__*.wav`, `slides/`, `slides.jsonl`, `analysis.json`, `конспект.docx/pdf`.
Настройки: `gui_settings.json` (автосохранение; ключи сливаются, не перезаписываются). Ошибки: `app.log`.

## Особенности машины владельца

- Ryzen 7 5700X (16 потоков), Radeon RX 7800 XT — **CUDA нет**, Whisper на CPU. Приоритет процесса поднимается до AboveNormal.
- Звук через SteelSeries Sonar. Teams выводит звук в виртуальный кабель «Teams transcriber» (VB-Cable), вход программы
  «Teams transcriber (захват)», выход пересылки — Sonar Aux (8 каналов, 96 кГц: открывать с родным числом каналов).
  Loopback снимает звук **после** регулятора громкости устройства; при тишине в устройство loopback не отдаёт данных.
- Виртуальная камера зарегистрирована как «HD Web Camera» (Unity Capture, 64+32 бит). Teams видит новые камеры
  только после полного перезапуска (выход через трей).
- Микрофон Arctis Nova Pro; веб-камера Logi C270 (занята Teams во время звонка — запись ролика тогда не работает).
- LLM: Gemini через OpenAI-совместимый эндпоинт, ключ в настройках. `gemini-3.6-flash` упирается в дневную квоту;
  рабочие бесплатные: `gemini-3-flash-preview` (анализ), `gemini-3.1-flash-lite` (подсказки).
- Журнал: логин владельца в `journal.json`; расписание/посещения работают.

## Правила работы с владельцем

- Общение по-русски, коротко, по делу. Владелец сидит на парах: **перед перезапуском окна спросить**, если идёт запись.
- Не выделять аудиторию в выводе пар (убрана намеренно). Темы занятий короче 3 символов или из цифр скрываются.
- Патчи кода делать скриптом с `assert old in s` (файлы большие, правки точечные); после патча `ast.parse`.
- UI проверять на `ui/index.html?mock=1` в браузере; бэкенд — `--file test_meeting.wav --model small`.
- Никогда не убивать `xray` широким `Stop-Process` — уронит VPN владельца.
